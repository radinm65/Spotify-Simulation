# Spotify UI Clone

A simple Spotify-inspired music streaming interface built using **HTML and CSS**. This project was created to practice and demonstrate fundamental front-end development skills, with a focus on layout, styling, and visual design.

## Features

- Spotify-inspired user interface
- Sidebar navigation and playlist sections
- Custom styling with CSS
- Image sizing and positioning
- Scrollbar styling and layout customization

## Technologies Used

- HTML5
- CSS3

## Purpose

This project is a front-end practice project focused on recreating the visual structure of a familiar music streaming platform without using JavaScript or any front-end frameworks.

## Disclaimer

This is an educational project inspired by Spotify's user interface. It is not affiliated with or endorsed by Spotify.
